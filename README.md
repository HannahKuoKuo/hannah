# ACE SIGN 公司網站優化

## 📋 專案概述

本專案是 ACE SIGN 公司官網的全面優化升級，包括：

1. **首頁設計** (`index.html`) - 優化的首頁，展示公司服務、成功案例和品牌承諾
2. **Newsletter 專頁** (`newsletter.html`) - 專門的新聞通訊頁面，用於展示 EDM 相關內容
3. **統一樣式** (`styles.css`) - 現代化的響應式設計系統
4. **交互功能** (`script.js`) - 提供平滑的用戶交互體驗

## 🎯 核心功能

### 首頁 (index.html)
- ✅ 專業的 Hero 區塊，展示公司核心價值
- ✅ 6 個核心服務方案卡片
- ✅ 4 個品牌承諾項目
- ✅ 4 個成功案例展示
- ✅ Newsletter 訂閱區域
- ✅ 聯絡資訊和表單
- ✅ 響應式導覽列和粘性導航

### Newsletter 專頁 (newsletter.html)
- ✅ 專屬的 Newsletter 英雄區塊
- ✅ 5 個文章分類過濾功能：
  - 新品發布
  - 設計提示
  - 成功案例
  - 優惠活動
  - 全部
- ✅ 6 篇 Newsletter 文章展示
- ✅ 分頁功能
- ✅ 訂閱表單

## 🚀 使用方式

### 在本地開發
1. 打開 `index.html` 在瀏覽器中查看首頁
2. 打開 `newsletter.html` 在瀏覽器中查看 Newsletter 頁面
3. 所有檔案都是靜態的，無需伺服器即可運行

### 推薦使用本地伺服器
```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js http-server
http-server
```

然後訪問 `http://localhost:8000`
